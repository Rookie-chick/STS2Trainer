# 21 · 功能 13：防御倍率（你受到的伤害 ÷N）

> [!important] 和 20 篇镜像：这次门禁反过来，对**玩家**那一侧做除法
> 20 篇：`rcx != 玩家` 时把伤害 ×N；这一篇：`rcx == 玩家` 时把伤害 ÷N。
> 除法要会写 `cdq; idiv`（有符号除法，否则负数伤害会算错）。热键：`Num +`

## 1. 目标

| 项 | 内容 |
|---|---|
| 要做的事 | 你受到的伤害 ÷4（可配），等于自带 75% 减伤 |
| 验收标准 | ① 敌人打你 20 → 实际掉 5 ② 你打敌人伤害不变 ③ 关掉恢复 |
| 热键 | `Num +` |

## 2. 原理

```csharp
// 同一层：Creature.LoseHpInternal(decimal amount, ValueProp props)
//   rcx = this(受伤者)   rdx = &amount   r8d = props
// 玩家受伤也会走这里（玩家也是一个 Creature）⇒ 门禁改成"rcx == 玩家"
```

另一种做法（更"正统"）：hook `Creature.DamageBlockInternal(decimal, ValueProp)` 放大"被格挡掉的伤害"，
但那改的是护盾吸收量，不是减伤；本作原版 "Defense Multiplier" 的语义更接近减伤，故用除法版最直观。

## 3. 我是怎么做的：怎么找出这个方法的（真实路径）

```text
① 复用 19/20 篇定位的 Creature.LoseHpInternal（真正扣血那一层）
② 想清楚方向：要"少掉血" ⇒ 把 amount 除小，而不是乘大
③ 除法注意：decimal 的 lo 是有符号 int，必须用 idiv（不是 div）
```

## 4. 你该怎么做：代码怎么写

```asm
; 门禁：功能开关开启 且 rcx == 玩家Creature
8B 02                 mov  eax,[rdx]        ; eax = amount.lo
99                    cdq                   ; 符号扩展到 edx:eax（idiv 前置动作）
B9 04 00 00 00        mov  ecx,4             ; 除数 N（这里 4；也占用 rcx 的低位没关系，
                                             ;   因为我们只在这里用一下，方法体的 rcx 已经不用了？→ 见"坑"）
F7 F9                 idiv ecx              ; eax = eax / 4
89 02                 mov  [rdx],eax
C7 42 04 00 00 00 00  mov  dword [rdx+4],0
C7 42 08 00 00 00 00  mov  dword [rdx+8],0
C7 42 0C 00 00 00 00  mov  dword [rdx+0xC],0
```

> [!danger] 别用 ecx 当除数（上面的写法是错的示范）
> `rcx` 是被挂钩方法的 `this` 指针，我们改它 ⇒ 方法体拿错对象 ⇒ 崩。
> **正确做法**：用别的寄存器，比如 `mov r8d,4`（r8d 是 props 参数，也要保）
> 或者最简单：**把除数写死在代码洞里，用 `mov eax,N; cdq; idiv eax` 之前先 `push/pop` 保存**。

安全版本：

```asm
50                    push rax
52                    push rdx
; …门禁判断（用 rax 做比较，不改 rcx）…
8B 02                 mov  eax,[rdx]
B9 04 00 00 00        mov  ecx,4          ; ← 这里改的是 ecx，rcx 高位也被清了！
; ↑ 所以必须在门禁比较"之后"才动 rcx，且动完要恢复 —— 见下
```

正确写法（不改 `rcx`）：

```asm
8B 02                 mov  eax,[rdx]      ; lo
99                    cdq
BB 04 00 00 00        mov  ebx,4          ; ← 用 ebx（先 push rbx 保存）
F7 FB                 idiv ebx
89 02                 mov  [rdx],eax
5B                    pop  rbx
```

## 5. 怎么验证

| 步 | 操作 | 期望 |
|---|---|---|
| 1 | 装完 `raw <入口> 16` | `E9 …` |
| 2 | 让敌人打你 | 掉血变成原来的 1/4 |
| 3 | 你打敌人 | 伤害不变 |
| 4 | `Num +` 关掉 | 恢复 |

## 6. 坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 用 `ecx` 当除数 | 崩（rcx 是 this） | 换 `ebx/esi`，且 push/pop |
| 用 `div` 不用 `idiv` | 负伤害/大数算错 | 用 `idiv`，前面加 `cdq` |
| 除完 mid/hi 没清 | 数值异常 | 16 字节全处理 |
| 门禁方向搞反 | 敌人变肉、你更脆 | 玩家侧用 `je`（相等才改） |

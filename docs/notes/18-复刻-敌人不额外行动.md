# 18 · 功能 10：敌人不额外行动

> [!important] 这一篇讲"拦战斗逻辑"
> 前面几个功能改的都是"数值/奖励"，这一篇改的是**行为判定**：
> 游戏在"敌人要不要再动一次"这个问题上会问一堆模型（遗物/怪物能力），
> 汇总点叫 `Hook.ShouldTakeExtraTurn`。让它**恒返回 false**，敌人就不会额外行动。
> 热键：`Num 9`

---

## 1. 目标

| 项 | 内容 |
|---|---|
| 要做的事 | 敌人不会额外获得回合/额外行动（原版叫 "Enemies Can't Move"） |
| 验收标准 | ① 有"额外行动"能力的敌人不再多动 ② 关掉后恢复 |
| 热键 | `Num 9` |

## 2. 原理

```csharp
// MegaCrit.Sts2.Core.Hooks/Hook.cs
public static bool ShouldTakeExtraTurn(ICombatState combatState, Player player)
{
    foreach (AbstractModel item in IterateCombatHookListeners(combatState))
        if (item.ShouldTakeExtraTurn(player)) return true;    // ← 任何一个模型说要，就返回 true
    return false;
}
```

- 只要**任何**一个遗物/能力/怪物模型说"要额外回合"，它就返回 true。
- 我们让它**永远返回 false** ⇒ 谁都不能要额外行动。

> [!warning] 这个功能"作用对象"要看清
> 名字里带 `player`，但它是被"敌人回合调度"调用的（问"这个玩家这一侧要不要给额外行动"）。
> 也就是：**它影响的是"额外行动"这一个开门条件**，不是"敌人完全不行动"。
> 如果你要的是"敌人一步都不动"，那是另一条链（敌人 AI 的行动队列），需要另找方法——
> 这也是原版把功能命名成 "Enemies Can't Move" 却挂 `ShouldTakeExtraTurn` 时**效果可能和名字不完全一致**的原因。
> ⏳ 本节把"挂法"教给你，**行为边界需要你实测确认**（见第 5 节）。

## 4. 你该怎么做：代码怎么写

### 4.1 钩子（直接复用 bool 版本，返回 0）

```csharp
var extraTurnOrig = g.FnExtraTurn >= 0x10000
    ? Hook.InstallForceReturnHook(h, g.FnExtraTurn, F(9), 0)   // 0 = false
    : null;
```

生成的机器码：

```asm
50                  push rax
48 B8 <&flag>       mov  rax,&开关
83 38 00            cmp  dword [rax],0
74 07               je   原样
58                  pop  rax
B8 00 00 00 00      mov  eax,0        ; false
C3                  ret
原样: <原 n 字节> ; E9 跳回
```

### 4.2 接入 Trainer

```csharp
// Game.cs
public ulong FnExtraTurn;
FnExtraTurn = Method("MegaCrit.Sts2.Core.Hooks.Hook", "ShouldTakeExtraTurn");

// Program.cs
var extraTurnOrig = g.FnExtraTurn >= 0x10000
    ? Hook.InstallForceReturnHook(h, g.FnExtraTurn, F(9), 0)
    : null;
// keys 加 (VK_NUMPAD9, false) → Num 9
// names 加 "敌人不额外行动"
// 退出：Hook.Restore(h, g.FnExtraTurn, extraTurnOrig);
```

## 5. 怎么验证（重点是"边界"）

| 步 | 操作 | 期望 |
|---|---|---|
| 1 | `methods … ShouldTakeExtraTurn` | 有地址 |
| 2 | 装完 `raw <入口> 16` | `E9 …` |
| 3 | 找一个**本来会额外行动**的敌人（带"再来一次"类能力），打一回合 | 它不多动 |
| 4 | 关掉 `Num 9` 再打同一类敌人 | 恢复多动 |
| 5 | 观察"敌人普通行动"是否仍正常 | 若连普通行动也没了 ⇒ 说明这条链比你想要的更宽，需要改挂更精确的方法 |

> [!danger] 别把它当"无敌"
> 这个功能**不减少敌人伤害**。它只改"要不要额外行动"。
> 想要"敌人完全不动"，得去 hook 敌人回合的行动队列（`MonsterModel.TakeTurn` 之类），
> 那属于进阶内容，本篇不展开（避免教你一个没验证过的写法）。

## 6. 坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 以为它能让敌人"完全不动" | 敌人照常攻击 | 认清它只管"额外行动"这一条 |
| 装完没变化 | 当前敌人本来就没有额外行动能力 | 换一个有多动能力的敌人测 |
| 关掉后仍不恢复 | 补丁没还原 | `Hook.Restore` 或重启游戏 |
| 0xFFFF | 未 JIT | 进战斗打一回合再来 |

## 7. 三类结论

### ✅ 已验证（方法层面）

| 结论 | 证据 |
|---|---|
| `Hook.ShouldTakeExtraTurn(ICombatState, Player)` 是"额外行动"的**唯一汇总点**（遍历所有模型） | 反编译源码 `foreach … if (item.ShouldTakeExtraTurn(player)) return true;` |
| 返回 bool ⇒ 强制返回 false 即可关闭 | 逻辑推导 |
| 原版 Trainer 挂的就是这个方法 | 知识库 [[70-拆解-Plus20 Trainer 的 20 个功能与改法]] 的字符串提取结果 |

### ❌ 已证伪

无（未实测）

### ⏳ 待验证

| 结论 | 怎么验 |
|---|---|
| 有多动能力的敌人不再多动 | 找对应敌人打一回合对比 |
| 普通行动不受影响 | 同一回合观察敌人是否仍正常攻击 |
| 关掉恢复 | `Num 9` 关掉再打 |

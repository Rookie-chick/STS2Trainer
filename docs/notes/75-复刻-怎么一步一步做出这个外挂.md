# 75 · 复刻指南：怎么一步一步做出这个外挂

> [!important] 先说清楚这份指南的"证据等级"
> - **✅ 已验证**：环境（启动/焦点/截图/键盘/读写内存）｜20 个功能对应的**游戏方法名**（从样本静态读出）｜字段名 `_currentHp/_maxHp/_currentBlock/_gold`｜AA 脚本语法与统计（17 define / 12 alloc / 1 aobscan）｜8 条已证伪

## 一、要复刻的东西长什么样（目标）

一个 **20 个功能**的 Trainer（键位 `Num 1~9/0/./+`、`Ctrl+Num 1~8`），机制是：
**按「类型::方法名」找到游戏方法 → 在方法入口打补丁 → 游戏自己按新逻辑跑** ✓

| # | 功能 | 热键 | 挂哪个方法（前缀 `MegaCrit.Sts2.Core.`） |

## 二、三条实现路线（选一条，别混）

| 路线 | 原理 | 优点 | 缺点 | 适合 |
|---|---|---|---|---|
| **A 值级** | 扫内存找数值地址，反复写 | 上手最快 | **.NET 堆里副本太多** ✗（我实测 4 种组合全假 ✗）；GC 会搬对象 | 只想改金币/血这种单值 |
| **B 方法级（AA 脚本）** ★=实例 | CE 的 `getmonomethod` 按名字取址 + `alloc/jmp` 打补丁 | **抗更新** ✓ 不依赖偏移 | 要会一点汇编 | **想做出同款 Trainer** ✓ |
| **C Harmony（C#）** | 用 Harmony 给方法加 Prefix/Postfix | 最干净 ✓ 不用汇编 ✓ | 需要把 dll 注入游戏 ⏳（加载方式未验证） | 会 C# 的人 |

> [!warning] 我的血泪建议
> **别从 A 开始** ✗ —— 我在这游戏上花了 4 轮：盲扫 int32/int64、加邻近值、加对齐、加精确 +4 —— **全部失败**（候选 239/68/3/0，写进去画面一分不变 ✗）。
> **直接走 B** ✓ —— 实例（Plus20）就是这么做的 ✓。

## 三、路线 B 全流程（零基础，8 步）

### 步骤 1：让游戏能跑、能看、能输
```powershell
# 启动（VM 无 GPU 必须加这个参数，否则 .NET 根本不加载）
& "D:\Games\Slay the Spire 2\SlayTheSpire2.exe" --rendering-driver opengl3 --rendering-method gl_compatibility
```
- 验证托管侧起来了：`python D:\sts2\sts2_wait.py` → 要打印 `coreclr=True sts2=True`
- 抢焦点（否则画面停帧、截图验证失效 ✗）：`python D:\sts2\focus_check.py` → 要打印"两帧差异 > 0%"
- 截图：`python D:\sts2\shot4.py t1`

### 步骤 2：装 Cheat Engine（绿色版即可）
`cheatengine.org` → 下载 → 解压 → 运行 `CheatEngine.exe`

### 步骤 3：附到游戏
CE 左上角"电脑图标" → 进程列表选 **`SlayTheSpire2.exe`** → 点"打开"
> 列表里没有？勾选左下"显示所有进程"；还是不行就用管理员运行 CE

### 步骤 4：打开 Mono 视图（关键）
菜单栏 **`Mono`** → **`Dissect mono`** → 出现程序集列表 → 选 **`sts2.dll`**（或 `MegaCrit.Sts2.Core`）→ 双击

### 步骤 5：找到类和方法（拿地址）
```
搜索框输入：Creature           → 双击 Creature 类
右侧列表里找到：set_CurrentHp  → 右键 → Copy address（或直接看它旁边的地址）
```
> [!tip] 记下两个东西
> ① `set_CurrentHp` 的**地址**（AA 里用 `define(address,…)` 就是它）
> ② `Creature` 的字段 **`_currentHp` / `_maxHp` 的偏移**（值级补丁要用，形如 `0x18`/`0x1C`）

### 步骤 6：写第一段补丁（无限血）
CE 菜单 **`Memory View`** → **`Tools → Auto Assemble`** → 粘贴：

```text
[ENABLE]
define(address,MegaCrit.Sts2.Core.Entities.Creatures.Creature::set_CurrentHp)
label(return)
alloc(newmem,$1000,MegaCrit.Sts2.Core.Entities.Creatures.Creature::set_CurrentHp)
newmem:
  // 进入 setter：rcx = this(Creature*)，rdx = 要写入的血量
  cmp dword ptr [infhp], 0
  je code
  mov rdx, [rcx + 0x1C]        // ← 0x1C 换成你 CE 里看到的 _maxHp 偏移
code:
  mov [rcx + 0x18], rdx        // ← 0x18 换成 _currentHp 偏移（补回原指令）
  jmp return
MegaCrit.Sts2.Core.Entities.Creatures.Creature::set_CurrentHp:
  jmp newmem
  nop
return:

alloc(infhp,4)                 // 开关变量：1=开 0=关
registersymbol(infhp)

[DISABLE]
MegaCrit.Sts2.Core.Entities.Creatures.Creature::set_CurrentHp:
  db <CE 自动填的原字节>
dealloc(newmem)
dealloc(infhp)
unregistersymbol(infhp)
```

然后：`File → Assign to current cheat table` → 表格里勾选它 → 回游戏挨一次打 → **血不掉 = 成功** ✓

> [!danger] 两个必须自己确认的点
> 1. **`0x18 / 0x1C` 这两个偏移**是从 CE 的 `Creature` 字段列表里读出来的真实值（我这边没有 ✗）
> 2. **[DISABLE] 里的原字节**：CE 里在方法地址右键 `Disassemble`，看前几字节；AA 编辑器的"恢复原始代码"会自动填 ✓

### 步骤 7：把其余 19 个功能照表补上
每个功能的写法都只有三种套路：

| 套路 | 适用功能 | 代码骨架 |
|---|---|---|
| **① setter 补丁**（拦写入） | 无限血 / 无限护盾 / 改金币 | `define(address, …set_Xxx)` + `mov rdx, 想要的値` + `jmp return` |
| **② 让函数直接返回**（什么都不做） | 无限能量 / 星星 / 敌人不动 / 商店免费 / 必给药水 | `define(address, …)` + `newmem: ret`（返回 true 用 `mov al,1`） |
| **③ 改返回值**（乘/改数） | 伤害/防御倍率、金币倍率、最大能量、药水槽、分数 | `newmem:` 里对 `eax/xmm0` 做 `imul/mulss/mov` 再 `ret` |

具体每个功能对应哪个方法 → 看本文第一节的表 ✓；完整 AA 模板 → [[73-复刻-20 个功能逐个实现（含代码）]] ✓

### 步骤 8：验证（唯一标准）
```
打开功能 → 让"该发生的事"发生一次 → 看画面
  无限血：让敌人打你 → 血条不掉 ✓
  改金币：买一次东西 → 金币不减（或变成你写的数）✓
  商店免费：进商店 → 价格显示 0 ✓
  伤害倍率：打一下敌人 → 伤害数字变大 ✓
```
> [!danger] 不要用"脚本没报错/字段写进去了"当成功判据 ✗（我在这个游戏上被它骗了 4 次 ✓）

## 四、我踩过的 8 个坑（照着躲，能省几小时）

| # | 坑 | 现象 | 对策 |
|---|---|---|---|
| 1 | 直接双击 exe（VM 无 GPU） | 弹 `Unable to initialize video driver`，进程活着但 `.NET` 不加载 | 加 `--rendering-driver opengl3` |
| 2 | 游戏失焦 | 画面停帧 ⇒ 截图验证整条失效（看起来像"改无效"） | `AttachThreadInput`+`SetForegroundWindow` 抢焦点，再连拍两帧确认在动 |
| 3 | 窗口最小化时截图 | 窗口变 159×27，抓出来全黑 | 先 `ShowWindow(SW_RESTORE)` 再 `PrintWindow(hwnd, hdc, 2)` |
| 4 | `PostMessage` 发鼠标 | Godot 用 raw input，**不认** ✗ | 用 `SendInput`（要前台）或干脆键盘 |
| 5 | 发 `Enter` 确认菜单 | 只移动选中，不确认 ✗ | 发 **`Space`** ✓ |
| 6 | **盲扫值找血量** | 239/68/3/0 候选 → 写进去画面不动 ✗ | 别盲扫 ✓ 先拿**偏移**（CE Mono）或直接走方法级 |
| 7 | 写成功 + 读回正确 | **不等于生效** ✗（HUD 一分不变） | 只认画面/数值的实际变化 |
| 8 | 编译引用 netstandard 库 | `CS1703 重复引用` / `CS0012 缺 netstandard` | `csc /noconfig /nostdlib` + 手动 `/r:` 全部 ref dll（Nupkg 解出来的 facades） |

> 另外两条（进阶才会碰到）：`.NET 9` 进程**不能用 ClrMD 2.4 附**（版本代差 ✗，要 4.x + net8 运行时）；`csc`（C# 5）**不支持 `ReadField<T>()` 这类泛型 API** ✗。

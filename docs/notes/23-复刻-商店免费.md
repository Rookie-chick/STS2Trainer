# 23 · 功能 15：商店里买东西不要钱

> [!important] 这是 15 篇（decimal 返回）的直接应用：**把价格返回 0**
> 唯一的新知识是"**必须提前装**"——价格在**进去商店时就算好了**，不是点击时才算。
> 热键：`Ctrl+Num 3`

## 1. 目标

| 项 | 内容 |
|---|---|
| 要做的事 | 商店里所有商品价格为 0（卡牌/遗物/药水/删牌） |
| 验收标准 | ① 进商店，商品标价 0 ② 买完金币不减 ③ 关掉恢复原价 |
| 热键 | `Ctrl+Num 3` |

## 2. 原理

```csharp
// MegaCrit.Sts2.Core.Hooks/Hook.cs
public static decimal ModifyMerchantPrice(IRunState runState, Player player, MerchantEntry entry, decimal result)
{
    decimal num = result;
    foreach (AbstractModel item in IterateHookListeners(...))
        num = item.ModifyMerchantPrice(player, entry, num);   // 会员卡等可以打折
    return num;                                               // ← 最终价格
}
```

⇒ 让它返回 **0**，所有商品免费。

> [!warning] 时机：**进商店之前**就要装好
> 商品价格在"生成商店"时就算完并显示在 UI 上；进去以后再装钩子，价格不会重算。
> 所以热键要在**走进去之前**按（原版说明里也写着"进商店前先按"）。

## 4. 你该怎么做：代码怎么写

```csharp
// 直接用 15 篇写的钩子，返回值 0m
var priceOrig = g.FnMerchantPrice >= 0x10000
    ? Hook.InstallForceDecimalReturnHook(h, g.FnMerchantPrice, F(13), 0m) : null;
// keys 加 (VK_NUMPAD3, ctrl:true) → Ctrl+Num 3；names 加 "商店免费"
// 退出：Hook.Restore(h, g.FnMerchantPrice, priceOrig);
```

生成的机器码（decimal 0 = 四个 0）：

```asm
C7 01 00 00 00 00        mov dword [rcx],0        ; lo
C7 41 04 00 00 00 00     mov dword [rcx+4],0      ; mid
C7 41 08 00 00 00 00     mov dword [rcx+8],0      ; hi
C7 41 0C 00 00 00 00     mov dword [rcx+0xC],0    ; flags
48 89 C8                 mov rax,rcx
C3                       ret
```

## 5. 怎么验证

| 步 | 操作 | 期望 |
|---|---|---|
| 1 | **进商店前**按 `Ctrl+Num 3`（控制台显示 `[开] 商店免费`） | —— |
| 2 | 进商店 | 所有商品标价 `0` |
| 3 | 买一张卡 | 金币不减（配合 10 篇金币锁更直观） |
| 4 | 关掉后进下一家商店 | 价格恢复 |

## 6. 坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 进店后才开 | 价格还是原价 | 提前开；或退出商店再进 |
| 有的商品不免费 | 某些条目走了别的定价路径 | 再挂 `MerchantEntry` 上的价格字段（进阶） |
| 买完崩 | 价格 0 导致某些校验异常 | 返回 1 而不是 0（几乎同样效果，更安全） |

## 7. 三类结论

### ✅ 已验证（方法层面）

| 结论 | 证据 |
|---|---|
| 商店最终价格由 `Hook.ModifyMerchantPrice(...)` 返回的 decimal 决定 | 反编译：遍历模型累加后 return |
| decimal 0 = 4 个 32 位 0 | decimal 布局 |
| 价格在生成商店时计算 | UI 显示的是已算好的值（原版说明也要求"进店前按"） |

### ❌ 已证伪

无
